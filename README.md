Forecasts every GTA VI (PS5) trophy's Exophase earn rate at the case target, as five quantiles (5/25/50/75/95%) in percent. Per trophy, a recency-weighted least-squares line of logit(rate) against log-time since launch is extrapolated to the target, with short histories shrunk toward their tier's median trend and the trend damped when the target sits far outside the observed range. The spread combines a random-walk term, an Exophase-refresh term, and the fit's residual scale, so it widens honestly over the 4.5-day final horizon. Node 22, standard library only, fully deterministic.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
